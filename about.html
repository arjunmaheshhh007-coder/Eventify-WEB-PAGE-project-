About Eventify

Eventify is a web application designed to help users add and view public events in a simple and organized way. The system allows event information to be entered through a form and stored in a MySQL database, then displayed on a dedicated View Events page.

This website was developed as part of a Web Design & Databases project using HTML, CSS, JavaScript, PHP, Apache, and MySQL. The aim was to build a functional and user-friendly platform while applying web design principles, form handling, client-side validation, and database connectivity.
